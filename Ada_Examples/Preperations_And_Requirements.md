# Requirements 
** For Linux 
** Ubuntu and Debian run the provider shell command below to run Ada. 
```sh
sudo apt install gnat
```
** For Fedora and CentOS run the shell command below 
```sh
sudo dnf install gcc-gnat (or) sudo yum install gcc-gnat
```
** For Gentoo Linux run the shell command Provider Below 
```sh
echo "sys-devel/gcc ada" >> /etc/portage/package.use/gcc
emerge --ask --verbose --oneshot sys-devel/gcc
```
** For Arch Linux Run the shell command provider below 
```sh 
sudo pacman -S gcc-ada
```
** For openSUSE run the shell command provider below 
```sh
sudo zypper install gcc-ada
```
** For alpine Linux run the provider shell command below 
```sh 
sudo apk add gcc-ada
```
** For Void Linux run the shell command provided below 
```sh
sudo xbps-install -S gcc-ada
```
# __For Windows__ 
** Run the following shell command below 
```cmd
pacman -S mingw-w64-ucrt-x86_64-gcc-ada mingw-w64-ucrt-x86_64-gprbuild
```
# For macOS 
** Run the following shell command provided below 
```zsh 
brew install gcc
```
# FOR BSD 
** For FreeBSD run the shell command provided below. 
```sh
sudo pkg install gnat14
```
** For OpenBSD run the shell command provided below 
```sh
sudo pkg_add gnat
```
# End of Requirements 
** Enjoy
